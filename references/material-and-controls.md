## 材质构造

先做一块连续面板，再安排深度。主读数附近有一处最深的开孔，按键与旋钮可用一条装配线分组，刻度和单位直接印在所属零件旁。把重复的圆角区块改成对齐、间距或浅接缝。手机上可以重排模块，但保持同一套深度关系。

| 层级 | 从正面可见的证据 |
| --- | --- |
| 机壳 | 面积最大、明暗最缓。边缘倒角有一圈窄亮边，底边露出壳体厚度。磨砂感只需要轻微的色差。 |
| 开孔 | 外壳切出一个边沿，里面还有一圈颜色较深的侧壁。让口沿上侧挡光、下侧接光，玻璃或活动件坐在开孔里面。 |
| 活动件 | 分开顶面、侧壁和安装缝。键帽与滑块的短接触影落在槽口里，旋钮的防滑纹只放侧壁，顶面可用浅浅的拇指凹面。 |
| 丝印与灯 | 文字和刻度紧贴面板，用稍深的油墨；指示灯嵌在小孔里，点亮时保留暗边。少量螺钉、铭牌、散热孔应有明确的安装或通风位置。 |

| 部件 | 构造与状态 |
| --- | --- |
| 实体按键 | 安装座固定，圆角键帽留 2–4px 的暗缝。静止时能看到底侧壁；按下时只让键帽下沉约 2–3px，侧壁与接触影同时收短。带锁定状态的键帽保持下沉，用小灯或可读标签补足反馈。 |
| 旋钮 | 固定的刻度和凹座承托可转动的厚圆帽。转动部分包含抓握纹、顶面与指针。起止角、端点文字和读数使用同一数值映射。已有原型为低、中、高三档，具体范围由使用场景决定。 |
| 横向 Slider | 轨槽窄而暗，短方滑块有侧壁、顶面握纹和一条位置标记。进度线可选；用了也保持细窄。让刻度对准滑块的中心行程，可操作范围大于可见的槽。 |
| 垂直推子 | 同样的窄槽与米白滑块，位置标记改为横线。让滑块中心对应刻度，最低值在底部。分组使用独立实例或独立状态，并在每一路标明用途、数值和单位。 |
| CRT / 液晶 | CRT 由壳体开孔、内斜壁和深玻璃组成，玻璃略圆，边缘渐暗。表面仅留一层柔弱的反光，扫描线需要放大才明显。屏内只放属于仪器的数据、网格和状态；屏外留型号、键名与单位丝印。 |

关键接触阴影可用面板油墨的 20%–35%，偏移约 2–6px，模糊约 3–6px。大壳体的光影比键帽轻。使用共享样式时，实际检查透明度和阴影方向。

## 原型与实际控件

- 现有 Figma 横滑和垂直推子用点击定位、拖动换档。垂直推子有 −18、−9、0、+9、+18 dB 五档，悬停显示当前通道的聚焦样式，方向键调相邻档。该 Figma 示例的悬停状态和拖动属于分档演示。
- 实际应用中的滑块应支持和业务一致的指针操作、键盘调节、可见焦点和可访问的名称与数值。根据业务定义范围、步长、格式和禁用行为。没有音频处理需求时，dB 与频率可换成任务所需的标签与单位。
