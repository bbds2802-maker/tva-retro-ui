# 触屏材质与层级

日历、计划和阅读类界面，先铺一块连续的暖灰哑光底面。用字重、对齐和留白组织内容；只有常用的独立操作和当前导航项需要浮起来。无须加设备外框、刘海或假状态栏。

| 元素 | 材质处理 |
| --- | --- |
| 正文、日期网格、普通导航 | 与底面共面。网格靠对齐和留白，不给每个单元加底板。正文用深灰橄榄墨色，小字也应有清楚对比。 |
| 日期详情、分组列表 | 底色只比面板略亮，一道低对比轮廓或分隔线即可，没有悬浮影。 |
| 翻页键、当前导航 | 键面沿用底面色，左上是短柔亮边，右下是偏灰的近距离接触影。按下时缩短投影，键面下移 1–2px。当前导航可加细描边和有色文字。 |
| 选中日期、事件 | 选中日期用小面积的高对比实色圆，避免每个日期都凸起。普通事件只放小点，另用日期详情表达名称与状态。 |

新项目可从面板 `#D8D5C5`、详情 `#DFDCCF`、油墨 `#414539`、中性边线 `#BDB9A8` 起步；亮影用米白，暗影用低透明度灰褐。橙色 `#AC4E28` 用于日期、选中轮廓等少量位置；青绿可沿用 `#263D38`。有原项目色值时以原项目为准。保持已选项与键盘焦点两种边界可区分。

对照[日历样张](soft-touch-calendar.jpg)或在浏览器打开[可交互日历](../assets/soft-touch-calendar.html)。参考其材质深浅、状态面积与留白；内容、布局和控件按目标任务重新组织。
